## China component selection

Use the Cambridge mainland China entry component set for the examination year. China used the following component codes; taking a generic variant 2 for every year would select the wrong 2025–2026 theory papers for the three sciences and Economics.

| Subject        | May/June 2024          | May/June 2025 and 2026 |
| -------------- | ---------------------- | ---------------------- |
| Physics 9702   | 12, 22, 33, 34, 42, 52 | 14, 24, 37, 38, 44, 54 |
| Chemistry 9701 | 12, 22, 33, 34, 42, 52 | 14, 24, 37, 38, 44, 54 |
| Economics 9708 | 12, 22, 32, 42         | 14, 24, 34, 44         |
| Biology 9700   | 12, 22, 33, 34, 42, 52 | 14, 24, 37, 38, 44, 54 |
| Geography 9696 | 12, 22, 32, 42         | 12, 22, 32, 42         |

Both science practical alternatives are retained: 33/34 in 2024 and 37/38 in 2025–2026. They are different component files. The final component digit is stored as the paper variant; it is not a substitute for the full China component mapping.

The mapping comes from these entry documents:

- [Cambridge June 2024 IAS/IAL entry codes, British Council mirror](https://www.britishcouncil.org.tw/sites/default/files/cambridge_june_2024_ias_ial_entry_codes.pdf): printed pages 41 Biology, 42 Chemistry, 44 Economics, 46 Geography, and 52 Physics identify the Zone 5 options and components.
- [Cambridge June 2026 China guide to making entries](https://www.cambridgeinternational.org/Images/724211-guide-to-making-entries.pdf): pages 40 Biology, 41 Chemistry, 44 Economics, 46 Geography, and 52 Physics identify the mainland China set. Its carry-forward entries also reference the changed 2025 AS components.
- [Cambridge June 2025 China component reference guide](https://www.cambridgeinternational.org/Images/724241-china-component-reference-guide.pdf): the indexed official text documents the bespoke mainland China components from June 2025. The original URL returned 404 on 2026-10-06; this limitation is retained in the external evidence record rather than treated as a currently downloadable guide.

Cambridge's [China exam security guidance](https://www.cambridgeinternational.org/exam-administration/cambridge-exams-officers-guide/phase-4-before-the-exam/exam-security-regulations-china/) also explains the bespoke China timetable. Administrative zone metadata alone must not be used to infer these components.

## External package layout and import

Downloaded PDFs and import manifests stay outside Git under `D:\Project\EXPW\deployment-as-a-level`. Repository changes contain the subject registration, archive support, tests, and documentation. The external folder has:

- `files/`: 168 original QP/MS/Insert PDFs.
- `official/`: five selected syllabus PDFs and supporting Cambridge entry-guide evidence.
- `listings/`: the 15 captured PapaCambridge season listings.
- `subjects-970x/`: source URLs, download inventory, component evidence, recovery notes, and mark-scheme audit.
- `packages/<subjectCode>/package.json` and `packages/<subjectCode>/files/`: the five resource-package-v1 manifests with declared local PDF files and checksums.
- `download-plan.json` and `pdf-audit.json`: the download plan and PDF header/page-count audit.

Use [structured resource package v1](structured-resource-package.md) and the shared validator/importer. Do not send these packages to the legacy MCQ splitter. Run the following from `D:\Project\EXPW\expassway`; the example imports all five local packages after applying the archive migration and its prerequisites.

```powershell
$archiveRoot = 'D:\Project\EXPW\deployment-as-a-level\packages'
$archiveSubjects = @('9702', '9701', '9708', '9700', '9696')

foreach ($subjectCode in $archiveSubjects) {
  $archiveManifest = Join-Path $archiveRoot "$subjectCode\package.json"
  node tools/validate-resource-package.mjs $archiveManifest
  if ($LASTEXITCODE -ne 0) { throw "Invalid archive package: $subjectCode" }
  node tools/import-structured-resource-package.mjs --package $archiveManifest
  if ($LASTEXITCODE -ne 0) { throw "Archive dry run failed: $subjectCode" }
}

node node_modules/wrangler/bin/wrangler.js d1 migrations apply expassway-db --local
if ($LASTEXITCODE -ne 0) { throw 'Local migrations failed' }

foreach ($subjectCode in $archiveSubjects) {
  $archiveManifest = Join-Path $archiveRoot "$subjectCode\package.json"
  node tools/import-structured-resource-package.mjs --package $archiveManifest --mode apply --target local --publish
  if ($LASTEXITCODE -ne 0) { throw "Local archive import failed: $subjectCode" }
}
```

Migration `0028_as_a_level_subject_archives.sql` registers the five subjects and permits science Paper 5 while retaining existing paper and practice-attempt data. Apply the full pending migration sequence in a fresh environment. The importer validates SHA-256 hashes and QP/MS references, uploads declared files to `expassway-content`, and then upserts D1 records in `expassway-db`. Local `--publish` enables catalogue QA in the local environment.

Before production publication, run the relevant repository checks, including `npm run test:as-level-archives` and `npm run check`. Check the local catalogue, syllabus edition/years, China component coverage, Paper 5 originals, Geography Inserts, download access rules, and the absence of practice buttons for these source-only papers.

For a reviewed production rollout, apply migrations, deploy the Worker/static assets, and import the same reviewed packages remotely:

```powershell
node node_modules/wrangler/bin/wrangler.js d1 migrations apply expassway-db --remote
if ($LASTEXITCODE -ne 0) { throw 'Remote migrations failed' }
npm run cloudflare:deploy
if ($LASTEXITCODE -ne 0) { throw 'Website deployment failed' }

foreach ($subjectCode in $archiveSubjects) {
  $archiveManifest = Join-Path $archiveRoot "$subjectCode\package.json"
  node tools/import-structured-resource-package.mjs --package $archiveManifest --mode apply --target remote --confirm-remote --publish
  if ($LASTEXITCODE -ne 0) { throw "Remote archive import failed: $subjectCode" }
}
```

The commands above describe the procedure and are not evidence of a completed live rollout. Confirm live publication through D1/catalogue counts and actual syllabus, QP, MS, and Insert download responses. Repeat imports use stable paper/resource keys. A remote draft import preserves an already published row's status and updates its metadata; review corrections locally before applying them remotely. When a paper later receives prepared questions, preserve those question rows and set `validQuestionCount` to the reviewed package's question count rather than reapplying the original zero-count archive record.
